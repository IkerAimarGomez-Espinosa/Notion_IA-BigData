# 44. Glosario del Case Study

## Authoritative data store

Fuente considerada como principal y confiable para determinados datos.

## PII

Personally Identifiable Information.

Información que puede identificar a una persona.

## Full-text index

Estructura diseñada para facilitar búsquedas sobre contenido textual.

## JSON

Formato de datos semiestructurado basado en pares clave-valor.

## Index seek

Acceso selectivo a datos mediante un índice.

## Index scan

Lectura de una cantidad más amplia de entradas de un índice.

## Partitioned table

Tabla cuyos datos se dividen lógicamente en particiones.

## Embedding

Representación numérica de contenido que permite trabajar con similitud semántica.

## Vector similarity

Comparación matemática entre representaciones vectoriales.

## Semantic search

Búsqueda basada en significado y contexto.

## Keyword search

Búsqueda basada en palabras o términos concretos.

## Hybrid search

Combinación de búsqueda vectorial y mecanismos basados en palabras.

## Chunking

División de contenido en fragmentos.

## RAG

Retrieval Augmented Generation.

Patrón en el que se recupera información relevante antes de que un modelo genere una respuesta.

## Fuzzy similarity

Medida de similitud aproximada entre textos.

## Recursive update

Situación en la que una actualización provoca otra actualización que vuelve a activar el mismo proceso.

- Qué consulta presenta problemas de rendimiento.
- Qué observa el plan de ejecución.
- Qué información contienen los informes de incidentes.

- Qué datos deben protegerse.
- Cómo deben limitarse los datos visibles por los analistas.
- Qué se exige para la telemetría.

- Qué papel tienen embeddings, chunking y vector similarity.
- Qué significa hybrid search.
- Qué relación existe entre búsqueda y RAG.
- Qué operaciones deben realizarse sobre `FeedbackJson`.
